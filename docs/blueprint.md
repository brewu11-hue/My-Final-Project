# **App Name**: TT CleanCities

## Core Features:

- Service Request: Allow users to submit waste removal service requests with location details and image uploads.
- Route Optimization: Use an algorithm to optimize waste removal routes based on submitted requests and truck capacity. Act as a planning tool that calculates optimal routes, with consideration for new and past requests.
- Real-time Tracking: Enable users to track the real-time location of waste removal trucks on a map.
- Reporting: Provide an overview of number of request, truck availabilty and overall performance in an intuitive way

## Style Guidelines:

- Primary color: A vibrant green (#76BA99) to represent cleanliness and environmental friendliness.
- Background color: A light, desaturated green (#E2F0D9) to create a clean and airy feel.
- Accent color: A complementary blue (#3B6064) to provide contrast and highlight key elements.
- Body and headline font: 'PT Sans' for a modern and readable look.
- Use simple, clear icons to represent different waste types and actions.
- A clean and intuitive layout with easy navigation and clear calls to action.
- Subtle animations for route changes and real-time location updates to provide feedback without distraction.
